# Explain Action

1. Read the active spec and inspect the actual feature diff. Do not infer delivered
   behavior from the spec alone.
2. Explain the user-visible result first.
3. Describe important data flow across React, FastAPI, services, and persistence only
   where those layers are involved.
4. Call out non-obvious decisions, tradeoffs, validation, security boundaries, and
   meaningful tests.
5. Distinguish completed behavior from planned or unverified behavior.
6. Link relevant local files. Do not modify code or documentation unless asked.
